# weekly-work-summary

将分模块罗列的工作记录，压缩为中文周报总结。支持自定义**字数范围**、**总结格式**和**输出内容格式**。

## 适用场景

- 你手头有按模块/分点罗列的本周工作内容（比如中控系统、链路、NLU、TTS/ASR 等技术模块）
- 需要把它们浓缩成周报总结，用于周报、汇报文档或群消息
- 希望保留专业术语原文，不做解释展开，风格简洁无套话

## 可配置参数

三个参数均可选，未指定时按默认值处理，可自由组合。

| 参数 | 默认值 | 可选形式 |
| --- | --- | --- |
| 字数范围 | 200 字以内 | `x 字以下/以内`、`m-n 字`、`x 字左右`（±10%） |
| 总结格式 | 列表清单（`  N）模块名：内容`） | 列表清单、一段话、分模块小标题、表格等 |
| 输出内容格式 | 普通文本 | 普通文本、Markdown、HTML |

> 说明：**总结格式**决定内容的组织结构，**输出内容格式**决定用什么标记语法呈现，两者正交，可任意组合（如"列表清单 + Markdown"）。默认列表清单的版式为行首两空格 + `N）` + 模块名 + `：` + 内容，各模块分行，不要连成一段话。

## 使用方法

直接把分点内容发给 Claude，并在请求中说明所需参数即可触发本技能。未提到的参数走默认值。例如：

```
对下面内容做本周工作总结，200字以内

1. 中控系统：
   1. 完成小度意图模拟能力...
   2. 完成接入协议改造...
2. 链路：
   ...
```

也可以指定其他组合，例如：

- `总结成列表，用 Markdown，150 字以内`
- `压缩成一段话，输出 HTML`
- `每个模块一个小标题，300-400 字`

## 输出示例

**输入**（节选自实际使用场景）：

```
1. 中控系统：
   1. 完成小度意图模拟能力：directive 组合与弹窗字段编辑、与接入协议独立转换，以及后台文本链路对比与流式协议推导。
   2. 完成接入协议改造：统一为 directive + payload，去掉扁平帧兼容；relay / 意图模拟对接裸帧上游，并支持小度凭据回退。
   3. 完成 remote NLU 与链路透传：remote NLU 改为 HTTP /nlu，链路记录实际上游入参；Navigation EndLoc 扁平槽嵌套后透传接入服务。
2. 链路：
   1. 自研链路 vad 配置，提供测试环境测评 App，本周完成小度私有化 ASR、腾讯 ASR 服务 vad、百度智能云 tts 人工智能隐性标识功能联调。
   2. 炯为 AI 玩具，成语接龙多轮 query 语料已提供，多轮 NLU 优化工作...
   3. 小度链路 vad 配置因其它逻辑规则导致 vad 无效问题，已稳定复现，确认修复方案，预计下周修复上线。
   4. 跟进自研链路 productId 相关问题，目前已支持产品参数提取，配置 NLU。
3. NLU：
   1. 上下文与规则：接入会话续问、Stage1 上下文 gate、LLM history；按 L0/L1/L2 收缩规则；兜底意图统一为 Other.Unknown。
   2. 热更新与编辑器：落地三资源内存快照热更新；Web 编辑器支持规则备份导入导出，补齐操作反馈与配置化启动。
   3. RAG 主链路优化：Stage2提槽链路默认关闭 RAG；Stage1意图识别链路候选缩 Prompt、拒识快兜底；强命中短路与子句并集。
4. TTS/ASR:
   1. TTS: 百度 TTS 接口新增 AIGC 标识入参。
   2. ASR: 为百度、字节、腾讯、阿里四家厂商新增 VAD 时长可控参数；修复腾讯语音识别会话无法正常结束问题。
```

**输出（默认：200 字以内 / 列表清单 / 普通文本）**：

```
  1）中控系统：完成小度意图模拟能力、接入协议统一改造（directive+payload）及 remote NLU 与链路透传优化。
  2）链路：完成自研 vad 配置及多厂商 ASR/TTS 联调，推进炯为 AI 玩具多轮 NLU 优化，确认小度链路 vad 无效修复方案，跟进 productId 支持。
  3）NLU：落地上下文续问与规则收缩、三资源热更新及 Web 编辑器能力，优化 RAG 主链路。
  4）TTS/ASR：完成百度 AIGC 标识接入、四厂商 VAD 时长可控参数新增，修复腾讯语音识别会话无法结束问题。
```

**输出（列表清单 / Markdown，且用户要求用 Markdown 列表符号）**：

```markdown
- **中控系统**：完成小度意图模拟能力，落地接入协议统一改造（directive+payload），优化 remote NLU 与链路透传。
- **链路**：完成自研 vad 配置及多厂商 ASR/TTS 联调，推进炯为 AI 玩具多轮 NLU 优化，确认小度链路 vad 无效修复方案，跟进 productId 支持。
- **NLU**：落地上下文续问与规则收缩、三资源热更新及 Web 编辑器能力，优化 RAG 主链路。
- **TTS/ASR**：完成百度 AIGC 标识接入、四厂商 VAD 时长可控参数新增，修复腾讯语音识别会话无法结束问题。
```

**输出（一段话 / HTML）**：

```html
<p>本周工作聚焦中控、链路、NLU 及 TTS/ASR 四大模块。中控系统完成小度意图模拟能力、接入协议统一改造（directive+payload）及 remote NLU 与链路透传优化；链路完成自研 vad 配置及多厂商 ASR/TTS 联调……</p>
```

## 自定义

- **字数**：需要不同字数（比如 300 字、500 字，或 `100 字以内`、`300-400 字`）直接在请求中说明即可，SKILL.md 中的规则会按你指定的范围走。
- **总结格式**：默认已是带序号的模块列表（`  1）模块名：…`）。想要一段话、分模块小标题或表格等结构，在请求中说明（如"总结成一段话"）。
- **输出内容格式**：想要 Markdown 或 HTML 便于粘贴到文档/网页，在请求中说明（如"输出 Markdown"）；HTML 只输出片段，不含 `<html>/<body>` 外层结构。
- **模块结构**：如果模块结构不同（比如不是"中控/链路/NLU/TTS-ASR"而是其他技术分类），技能同样适用，因为它是按"最外层编号=模块"来识别结构的，不依赖固定的模块名称。
