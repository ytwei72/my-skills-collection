# 【系统名称】需求概览

> 依据【建设方案 / 立项需求说明书及版本日期】提炼。本文件用于快速把握建设意图、本期范围和验收主线，**不替代** [需求分析总览](./总览.md) 里的条款。
>
> 条款化研发基线见总览台账。本文件保留叙事摘要与完成度对照；后续增量以台账为准。

| 项目名称 | 【系统名称】 |

| 本期核心交付 | 【一两句，和总览「范围」一致】 |

| 排期叫法 | **一期 / 二期 / 三期** 指建设分期；实施计划里的分段另起名字，见 [U3](./通用规格/用语与优先级.md) |
