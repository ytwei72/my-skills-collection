# 对象状态与数据口径

> 台账：[需求分析总览](../总览.md)
> 关联：【链到入库、审核、发布、检索等需求】

主对象叫【知识条目 / 工单 / 申请，选一个产品名，并写入术语表】。附件、文件和日志是它的组成部分，不单独当主对象。

## M1 必填与身份

| 项 | 口径 |
|----|------|
| 必填 | 【缺了就不能进入下一状态的字段，用业务名称】 |
| 身份 | 【谁产生、谁提供、谁发布；三者可以不是同一主体】 |
| 标识 | 【对人可见的编号规则；内部主键不写在这里】 |

## M2 状态

| 状态 | 谁可以进入下一状态 | 对外可见 |
|------|--------------------|----------|
| 【草稿】 | 【编辑】 | 否 |
| 【待审核】 | 【审核人，且不得是提交人】 | 否 |
| 【已发布】 | 【另一人发布】 | 按权益 |
| 【已下架】 | 【具备下架权限的人】 | 否 |

自动处理的结果不得直接进入已发布。提交人不能对自己提交的对象做最终发布。

## M3 来源等级

| 等级 | 含义 | 使用限制 |
|------|------|----------|
| A | 【权威原文】 | 【可单独作为依据】 |
| B | 【研究或加工】 | 【须标明不是原文】 |
| C | 【外部投稿】 | 【须有授权和署名】 |
| D | 【线索】 | 【不得当作已核实事实发布】 |

等级不够时删行，不留空等级。

## M4 自动结果

机器抽取、翻译、摘要和关联默认是建议。对外展示或进入检索前，须经【哪一类人】确认。未确认的结果不得标成已核实，也不得当作强关联。
